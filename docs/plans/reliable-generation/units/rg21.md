# RG21 — Session-aware forwarding

Read shared documents and evidence E3/E5/E9. Prerequisite: RG20.

## Goal

An application can forward authorized user operations without writing token handling or a
general-purpose reverse proxy.

## Work

- Bind declared user-identity calls to generated callee-operation handles. The adapter obtains
  the session's access token internally and also applies RG09 workload identity. Product policy
  sees caller facts and operation results, never raw access/refresh tokens.
- Forward a finite header set, preserving contract-required ETag, Allow, content type and retry
  information. Do not forward arbitrary browser Authorization, Cookie, Host or credential headers.
  Validate input/output through the declared contract and use RG03 remaining budgets.
- Permit at most one coordinated refresh/retry after an eligible authentication refusal. A
  possibly performed mutation is retried only under its generated idempotency/recovery contract.
  No automatic retry of arbitrary POSTs or replay to a different target.
- Keep route maps and composite product responses application-owned, using the public operation
  API. Do not embed QRWTY path names, subscription policy or account-deletion orchestration.
- Make all applicable authoring/support/blueprint behavior truthful and refuse forwarding to an
  undeclared audience, unsupported identity contract or unavailable target operation.

## Acceptance

A valid user reaches the declared callee with valid workload identity; a copied browser header
cannot impersonate a workload. Tokens are absent from product hooks and logs. One refresh retry
works for a safe operation; unsafe/uncertain mutations are not blindly resent. Header/budget
semantics match direct calls. A renamed label changes neither recipient nor operation identity.

## Emitted surface and checks

Session-aware target adapters, capability contracts and route-operation scaffolds. Standard
checks, bounded proxy/header/retry cases and mouse/chat parity if normal authoring changes.
Full composed behavior is RG23.
