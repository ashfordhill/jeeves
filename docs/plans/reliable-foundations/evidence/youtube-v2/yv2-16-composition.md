## Necessary integration corrections

Foundation formerly had one HTTP slot; this unit adds only the finite Upload/Watch/Search edge,
static browser slot and selected public-media proxy, without a router DSL. Source exposure now
controls actual external API routing. Actual normalized HTTP/SQL/cache/consumer/query settings
feed constructors, while fixed single-instance/provider/batch/outbox/ladder policies match the
implemented mechanisms. [Full setting-to-constructor audit](../../youtube-v2/interfaces.md#yv2-16--video-attachment-and-complete-youtube-local-recipe).

The first provider run exposed foundation setup treating mounted provider-generated S3 keys as
ordinary secrets, causing safe single-use bootstrap refusal. The fix excludes those keys from
placeholder creation/initial hashes, then hashes the real keys after bootstrap/owner revocation.
Only that owned failed scratch was removed. Clean final first-run and strict normal restart pass.
Base attachment also removes its omitted publication module along with the channel. Identity role
vocabulary is an explicit recipe contribution: only YouTube adds creator; base setup has no product
role. Fresh offline setup checks confirm both vocabularies and no placeholder S3 keys. Captured
creation defaults explicitly choose local HTTP/private-network intent; reads/renders preserve
and diagnose incompatible historical source. Existing lifecycle/transport/cache/count/search
algorithms and query/browser contracts were not rewritten.
