# UX07a — Compact application, package and C1 inspectors

Implemented on primary `main` following `f8927e4aea9a89d9b3ae44670b0aab6451ee8709`.
The temporary `?studio=next` route remains opt-in. Runtime/template availability is unchanged;
P73a/P73b and the backend batch remain paused.

The inspector consumes the catalog's explicit field descriptors and the UX06 shared draft
controller. It covers Microservice, Browser app, Worker service, Billing, Redirect, Notifications
and Identity. Only populated General/Options/Connections sections appear; one section has no tab
strip. Provider choices stay settings on the existing element. Billing remains one C2 card.
Browser delivery has no Docker or language claim. Optional concurrency is blank when unspecified;
range, integer and incomplete numeric input are validated before any write.

Managed execution reveals Host; switching to Docker removes it in the same draft/batch. Browser
bundling removes the standalone provider, and returning to standalone removes the serving reference
and explicitly starts the new hosting choice as unspecified. Served by selects an actual application,
including a package member, never a package or resource. Redirect shortcuts select an existing real
outgoing database/cache connection and distinguish multiple connections by action/protocol. Clearing
a shortcut removes only that setting. Dependencies can be inspected through their actual identities.
No provider request, resource, adapter or network relationship is fabricated by these controls.

C1 system/person/external objects and packages use the same controller for canonical name/purpose.
An empty document can acquire C1 text without adding studio defaults. Package members are listed
and individually inspectable; languages/execution stay on those members. Known and unmapped legacy
elements expose only safe canonical text. Unknown studio definitions remain unresolved/read-only.
Rich legacy backend, interfaces, contracts, scenarios and deployment declarations stay preserved.
There is no route to the historical business/backend editors from these forms.

The exact queue keeps resource and individual-connection forms in UX07b, base creation in UX08a,
and dependency creation/membership/Ungroup in UX08b. Consequently this unit selects **existing**
Redirect dependencies and lists/navigates existing package members; it does not implement those
later actions early. Graph routing, placement and drag remain their later geometry assignments.

The direct guarded Chromium inspection is recorded in [browser observations](browser-observations.json).
It uses owned disposable projects and real server acknowledgements; the write guard precedes page
creation and allows only exact owned project IDs and operations/history/layout routes. Assertions
cover save/reload for every application row and conditional branch, provider choices, numeric bounds
and clear, invalid abandoned drafts, C1, empty documents, package member language independence,
Redirect reference preservation/navigation, and exact portable round trip. Network observations
retain operation targets and snapshot hashes instead of duplicating the rich backend model.
[Saved typed values](saved-settings.json) show the final source values, not display defaults.

The rich Discourse source copy is compared as a whole after editing only the API and C1 name/purpose:
all other values match, and its backend SHA-256 remains exact. The original factory is never changed.

horizontal overflow. See the long-name captures at [1440×900](screenshots/billing-long-name-1440x900.png)
and [1280×800](screenshots/billing-long-name-1280x800.png), plus

raw exploratory scripts/logs remain in the ignored workspace and are not a maintained test suite.
