# P24: compiled resource-workspace component

Experimental `@jeeves/resource-workspace@0.1.0` supplies account access, owner-resource lists, details, create/update drafts, cursor pages and required relationship selection. The [contract](../../../packages/resource-workspace/README.md) defines its finite supported envelope. This package is the component proof; diagram generation/configuration follows in P25.

The final composed proof is `.jeeves-work/runs/2026-10-31T08-16-47-828Z-resource-workspace-7bcb6336.{json,log}`: passed in 58.8 seconds, unchanged source, no model calls. One browser journey covers six scenario groups: account access, owner isolation, resource forms, relationship paging, record paging, and session lifecycle/responsive accessibility. It builds the compiled archive into a fresh generated Inventory service/frontend with an isolated Postgres volume. Account restoration distinguishes a scoped 500 error/Retry from an anonymous scoped 401. Real mutations use ordinary fetch, cookies and in-memory CSRF. Expiry clears account data; a second owner sees no first-owner records.

Strict diagnostics remain active for unexpected requests/statuses, broken assets, uncaught exceptions and console errors. Axe checks include account, server-unavailable, both presets, narrow record pages and the fixed-footer form. Generation integrity, regeneration retention of the reviewed frontend integration, and exact archive bytes are checked. Temporary containers, images, volumes and output are removed.

Screenshots inspected: [account](account.png), [Midnight](workspace-midnight.png), [Paper](workspace-paper.png), [record form](record-form.png), [480px records](workspace-narrow.png), [480px form](record-form-narrow.png). Paging is below the bounded page, reachable by ordinary scrolling. Full record values are available through View.

Early focused runs exposed actual protocol/UI integration issues: PATCH requires all required fields/relationships, anonymous/error screens needed headings, and cancellation of already-completed/error response bodies manufactured browser network failures. The final transport drains bounded bodies and detaches cancellation after completion; no error suppression was widened. An explicit browser context supports axe's analysis page. Fixture-only edge binding and Docker vendor paths were corrected.
