# QRWTY v2 sequential assignments

Give one numbered row to one fresh worker. Work from top to bottom. Each row names its inputs, one deliverable, and what a different person must be able to verify. The previous accepted handoff is an input to every row. The coordinator supplies its actual commit and paths. Use the [dispatch and return templates](v2-coordinator-prompt.md). The [field plan](v2-build-plan.md) supplies the common contract, load targets, line-count method and release criteria.

**Workspaces.** Product code, editable product hooks and SQL belong in the new QRWTY field repository. The source archive, pristine export commit (G0), both v1 checkouts and generated-owned files are immutable inputs. Write evidence paths below relative to `docs/evidence/v2/` in the field repository. Each assignment also returns `units/<ID>.md` with its evidence and next handoff. Evaluators keep hidden cases, comparative observations and solutions in a separate evaluator workspace until judging ends. Publish only their hashes and public requirements to builders. Give review workers the pinned, released evidence.

Commit each completed unit's public changes locally in the field repo. For a sealed assignment, return its private artifact hash and put only the permitted handoff in the field repo. Resume from the matching commits and hashes if the coordinator changes.

**Checks.** A row mentioning an acceptance ID points to the frozen v1.6 neutral pack. Run the relevant public slice while building. Run the complete frozen row when all its prerequisites exist in V16 or V25. Record outstanding subchecks explicitly. Use the evaluator protocol for a mixed row, missing capability or unavailable provider. A task that honestly records a failing outcome can supply valid comparison evidence. Only the measured behavior receives a pass. [Oracle row list and commands](https://github.com/ashfordhill/qrwty/tree/4f4940155eabb7b5e4dc4789f4c6137a61434725/docs/benchmarks/neutral-pack/v1.6/oracle)

The coordinator can read the pack at `/home/ash/github/qrwty/docs/benchmarks/neutral-pack/v1.6/`. B's copy is at `/home/ash/github/qrwty-baseline/docs/neutral-pack/v1.6/`. A builder's contract section below means the corresponding section of `frozen/http-contract.md`. Supply the relevant rows of `frozen/decisions.md` for policy and fixture values. The evaluator uses `frozen/acceptance-oracle.md` and the executable `oracle/` directory. Resolve actual extension paths from V04's inventory and put them in the individual dispatch.
