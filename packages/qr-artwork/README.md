# @jeeves/qr-artwork 0.1.0

A server-side domain component for reproducible QR artwork. The package exports `renderArtwork(canonicalUrl, settings, "png" | "svg")`, strict settings, immutable default settings and four reviewed presets. The separate `/settings` entry is browser-safe; it does not import the encoder, rasterizer or decoder. No model/provider or external network call is involved.

Inputs are an already canonical HTTP/HTTPS public URL (no credentials, at most 2048 characters) and the complete configuration: opaque six-digit foreground/background colors, square or rounded modules/finders, size 256/512/1024, quiet zone 4–8 and error correction M/Q/H. Dark foreground, lighter background, at least 7:1 contrast and at least three actual pixels per module are conservative constraints for this finite preset family. The app theme is independent of the artifact colors.

`qr-artwork@0.1.0` pins qrcode 1.5.4, pngjs 7.0.0 and jsQR 1.4.0. It builds one integer-pixel geometry for PNG and static SVG. Every call independently decodes the PNG raster and requires the exact input URL. Results include bytes, MIME, SHA-256, renderer version and measured module/quiet-zone/contrast information. Identical inputs reproduce identical bytes in the supported Node 24 environment. Persist the canonical URL, full settings and renderer version in an immutable revision; retain the pinned renderer or issued bytes when upgrading. A mutable destination is deliberately absent from this API. This renderer does not replace the legacy qrwty 512px endpoint.

Verification covers all four presets at all three sizes, M/Q/H correction across that matrix, 90-degree rotation with 15% white blending, all four module/finder combinations, the actual quiet border, invalid settings and byte reproducibility. Twelve additional Chromium cases rasterize the exported SVG and independently decode those screenshots. The per-call `pngDecode` result describes the PNG raster, including when returning SVG; it is not a claim that the server independently rasterized SVG. No physical print/device matrix, logo overlay, arbitrary artistic distortion, inverted symbols or universal scan guarantee is claimed.

The four-module minimum follows [DENSO's quiet-zone guidance](https://www.qrcode.com/en/howto/code.html). Encoding uses [node-qrcode](https://github.com/soldair/node-qrcode), while the independent decoder is [jsQR](https://github.com/cozmo/jsQR). Contrast and pixel limits above are this component's conservative product policy, not a QR-standard scan guarantee.

Workspace exports TypeScript source. `pnpm --filter @jeeves/qr-artwork pack --pack-destination <dir>` builds the compiled ESM artifact and declarations. Changing rendering behavior or presets requires a new renderer/package version. The library has no storage, authorization, upload or web-routing responsibilities; the consuming contract must supply those boundaries.
