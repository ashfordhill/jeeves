# YouTube v3: custom paths in `app/`

`app/` started as a byte-for-byte copy of `generated/` in the commit `V3-12: v3 generated output`
([contract](../../../../docs/plans/youtube-v3/contract.md) §6). This table has one row for each
path that a later unit adds to or changes in `app/`. It says the area, the unit that made the
change, and what was written and why.

- **Areas:** hook, stub body, product SQL, UI or integration, plus test (product unit tests,
  outside `src/` and outside the LOC metric). UI is the browser in `browser/` and `public/`
  (V3-16), excluded from the backend LOC metric by the scope's `uiPaths`.
- **Not listed:** `generated/` (it is never edited), and the build and runtime output that
  `.gitignore` keeps out of Git (`node_modules`, `dist`, `dist-public` and `.runtime`).
- **Check (V3-17):** the rows must match `diff -rq generated app` with those four left out.
- **Scaffold edits** (marked "scaffold edit" below): six, for two reasons.
  - **V3-15:** `src/modules/dependencies.ts` and `src/runtime/module-clients.ts`, so a module can
    name its message's ID ([template gap 6](README.md#template-gaps-found-while-completing-app)).
  - **V3-16:** `infra/edge/nginx.conf`, `compose.yaml`, `package.json` and `.gitignore`, so the
    edge serves the browser: the export serves no browser and has no place for one
    ([template gap 8](README.md#template-gaps-found-while-completing-app)).

  No other generated scaffold (`src/processes/`, the rest of `src/runtime/`, `src/features/`,
  `entry.ts`, the rest of `infra/`, the export's `scripts/`, `Dockerfile`, `tsconfig.json`) has
  been changed.
